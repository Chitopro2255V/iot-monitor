# IoT Monitor

Sistema de monitoreo IoT simulado: un ESP32 (simulado en Wokwi) envía
lecturas de temperatura a una API en FastAPI, que las guarda en una
base de datos y las muestra en un panel web.

## Estructura
- `firmware/`: código del ESP32
- `backend/`: API con FastAPI
- `frontend/`: panel web
- `docs/`: diagramas y capturas
